Cloud sync — phone + laptop

Sync via Firebase Realtime Database. Free, no build, no SDK.

Setup (5 min):
1. Go to console.firebase.google.com → Add project
2. Build → Realtime Database → Create Database → Start in test mode
3. Copy the URL at the top (looks like https://xxxx-default-rtdb.firebaseio.com)
4. Paste it above, pick a sync code, click Enable sync
5. Open the site on your phone, paste the same URL + code → Enable sync
